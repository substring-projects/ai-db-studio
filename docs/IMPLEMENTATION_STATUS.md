# Implementation status

AI DB Studio is pre-release software. See the [README](../README.md) for what it does, and its known limitations section for what remains.

## Verified

- PostgreSQL 17 and MySQL 8.4, on macOS: connections, schema browsing, table data, manual SQL, cancellation and query review.
- The AI assistant, using LangChain's OpenAI and Ollama clients against local stand-in servers.

## Implemented, not yet verified against a live database

Covered by unit tests of the generated SQL for both PostgreSQL and MySQL, but not yet run end to end against a server.

- **Create table designer:** column types for each engine with size and precision, primary keys (including composite), NOT NULL, auto-increment (`GENERATED BY DEFAULT AS IDENTITY` on PostgreSQL, `AUTO_INCREMENT` on MySQL), unique, defaults, CHECK constraints, column and table comments, foreign keys with ON DELETE and ON UPDATE, single and multi-column indexes, MySQL UNSIGNED, `ON UPDATE CURRENT_TIMESTAMP`, storage engine, character set and collation, and a live SQL preview. Definitions are validated before anything runs.
- **Foreign key picker:** when inserting a row or editing a cell, foreign key columns offer a searchable list of rows from the referenced table, labelled with a readable column such as `name` or `email`. A value not in the list can still be typed.

Version notes for MySQL: defaults on TEXT, BLOB and JSON columns and the `(UUID())` default need 8.0.13 or newer, and CHECK constraints are enforced from 8.0.16.

## Not yet verified

- A real AI model.
- Windows and Linux.
- Current installers: rebuild them, because the ones built earlier predate the current interface.
- Other database versions, MariaDB and cloud-hosted databases.

## Planned

- **Large tables (millions of rows):** estimated row counts shown immediately, keyset paging instead of OFFSET, export streamed straight to a file, streamed query results, and time limits and index-friendly search for filters and the foreign key picker. Today these work but slow down on very large tables.
- **In-app updates:** check GitHub Releases and offer the right download for the platform, then one-click install on Windows. Full automatic updates on macOS need signed and notarized builds.

## Before a stable release

- Verify TLS certificates.
- Sign the installers.
- Complete a full third-party license review.
